Robot Blackjack Attack: asset attributions
===========================================
Master reference for third-party assets. This file is NOT shipped and NOT read by the game.
The in-game Credits screen is defined in src/ui/game-view.ts (const CREDITS); keep the two in
sync. The in-game copy shows URLs as plain text (no <a> links) because the game runs inside the
CrazyGames iframe, which restricts outbound navigation, and CC BY needs no hyperlink.

It lives in docs/, NOT in src/assets/, on purpose. Vite emits a file from src/ only when something
imports it, so sitting in the asset folder it was kept out of the bundle by nothing more than "no
module happens to import it" — one import.meta.glob('../assets/*') away from being published. From
docs/ it is structurally unshippable. That matters because this file is internal notes: it carries
TODO reasoning, packaging internals, and a third party's personal email address, none of which
belong on a public CDN. (public/ is the ONLY directory copied verbatim into the bundle; that is
where OFL.txt lives, because the OFL requires it be distributed.)
